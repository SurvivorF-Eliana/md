> **NeoMark** is an ultra-sleek, distraction-free Markdown Editor and Real-Time Previewer engineered with **Host Grotesk** typography, industrial aesthetics, client-side session persistence, and advanced developer features.

---

## 🚀 Key Features

* **🎨 Host Grotesk & JetBrains Mono Typography:** Engineered with Google Fonts' *Host Grotesk* for clean, modern interface reading and *JetBrains Mono* for crisp code block editing.
* **⚡ Live HUD Metrics Bar:**
  * Real-time Word Counter.
  * Real-time Character Counter.
  * Estimated Reading Time (`1m read`, `5m read`).
* **📐 Triple Viewing Modes:**
  * **View Mode:** Full-screen rendered document reading.
  * **Split Mode:** Side-by-side real-time synchronized editing and instant preview.
  * **Edit Mode:** Focused, wide text area editing.
* **🧭 Automated Table of Contents (TOC):** One-click outline drawer that automatically parses document headings (`# H1, ## H2, ### H3`) for instant smooth-scrolling navigation.
* **📝 Built-in Boilerplate Templates:** Dropdown menu to instantly inject pre-built Markdown structures:
  * GitHub `README.md`
  * Diagnostic / Server Health Report
  * API Documentation
  * Product Changelog
* **📤 1-Click Export Tools:**
  * Export/Download `.md` file.
  * Copy rendered HTML snippet directly to clipboard.
* **🌓 Dual Theme Engine:** Smooth dark/light mode toggle with sci-fi cyan and violet glow accents.
* **💾 Local Storage Persistence:** Automatically saves open tabs, active document selection, and editor state across browser sessions.

---

## 🛠️ How to Use

1. **Launch:** Open `NeoMark.html` in any modern web browser (Chrome, Firefox, Edge, Safari).
2. **Import or Create:**
   * Click **"+ Nuevo"** to create a fresh Markdown tab.
   * Click **"Cargar .md"** or **drag and drop** `.md` files directly onto the sidebar.
   * Select a pre-built template from the top header dropdown menu.
3. **Format & Edit:** Use keyboard shortcuts or the top formatting toolbar to add headers, bold text, code blocks, tables, checklists, and images.
4. **Export:** Click **"Export"** to download the clean `.md` file or **"HTML"** to copy the styled HTML code.
